# Laborator-1

## Название проекта
Laborator-1 — работа с GitHub: репозитории, ветки, PR, Issues, Figma.

## Краткое описание
Данный проект представляет собой лабораторную работу, в которой выполняются основные действия на GitHub: создание репозитория, загрузка файлов, работа с ветками, оформление README, добавление ссылок и скриншотов.

## Цель работы / задачи
- Научиться создавать и настраивать репозитории.
- Загружать файлы различных форматов (PDF, DOCX, PNG).
- Создавать ветки и выполнять изменения в них.
- Создавать Pull Requests и Issues.
- Добавлять ссылки на прототипы Figma.
- Работать с README.md и оформлять проект.

## Инструкции по использованию файлов
1. Открой репозиторий на GitHub.
2. Перейди в нужную папку или файл.
3. Для просмотра PDF/DOCX — кликни по файлу.
4. Для загрузки — используй кнопку **Download**.
5. Ссылки на Figma можно открыть прямо в браузере.

## Структура проекта
- `README.md` — описание проекта.
- `images/` — скриншоты (если добавлены).
- Папки лабораторных работ (folder1, folder2 и др.).
- Загруженные PDF/DOCX файлы.
